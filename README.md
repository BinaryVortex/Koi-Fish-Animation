# Koi Fish Animation

A lightweight, browser-based koi fish simulation built with **HTML**, **JavaScript**, and the **Canvas API**.
The project renders a full-screen animated pond scene where multiple koi continuously swim with boid-inspired movement behavior.

## Features

- **Animated koi school**: draws multiple stylized koi fish with smooth body and tail motion.
- **Boid-style behavior**: nearby fish influence each other through local separation-style rules for natural group movement.
- **Full-screen canvas rendering**: automatically fills the viewport for an immersive animation.
- **Continuous animation loop**: uses `requestAnimationFrame` for fluid browser-native motion.
- **Touch input hook**: includes touch tracking logic that can be extended for richer interaction.

## Tech Stack

- **HTML5** for page structure
- **Vanilla JavaScript (ES6+)** for simulation and rendering logic
- **Canvas 2D API** for real-time drawing
