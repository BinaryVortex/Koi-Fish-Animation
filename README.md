# Koi Fish Animation

A beautiful and mesmerizing animation of koi fish swimming gracefully in a digital pond, built entirely with HTML and JavaScript using the HTML5 Canvas API.

## Features

- **Real-time Animation**: Smooth, continuous movement of multiple koi fish.
- **Boid Behavior**: Fish exhibit realistic flocking behavior, maintaining distance from each other.
- **Interactive Elements**: Touch or move your cursor to influence the fish movement.
- **Full-Screen Experience**: Optimized for full-screen viewing on any device.
- **Dynamic Colors**: Each fish has unique, vibrant colors generated randomly.
- **Trail Effect**: Subtle trail effect creates a pond-like ambiance.

## Technologies Used

- **HTML5**: Structure and canvas element.
- **JavaScript (ES6)**: Logic for animation, fish behavior, and canvas drawing.
- **Canvas API**: For rendering the graphics and animations.

## How to View

You can view the animation in several ways:

1. **GitHub Pages**: Visit [https://binaryvortex.github.io/Koi-Fish-Animation/](https://binaryvortex.github.io/Koi-Fish-Animation/) to see it live.
2. **Local Viewing**: Clone the repository and open `index.html` in a modern web browser.
3. **Download**: Download the files and open `index.html` directly in your browser.
